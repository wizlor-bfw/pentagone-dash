# Crédits — modèle 3D du cerveau

- Modèle : « Human Brain » (version light, 399 998 triangles), Grab3D — https://grab3d.com/models/anatomy/human-brain/
- Fichier source : https://grab3d.com/dl/human-brain/human-brain-light.glb (téléchargé le 14/10/2026)
- Licence : CC0 1.0 Universal (domaine public), usage commercial autorisé, sans attribution obligatoire (indiqué sur la page du modèle).
- Transformation : tools/make_brain_model.py — 34 000 sommets échantillonnés pour le nuage, maillage décimé à 1,5 % pour le fil de fer, chemins de surface (Dijkstra), régions thématiques assignées par position (lobes approximatifs, décoratifs). Sortie : brain_model.bin (~310 Ko) + brain_model.json.
